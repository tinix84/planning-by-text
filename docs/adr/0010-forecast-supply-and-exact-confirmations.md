# Forecast supply includes all active booking states

Date: 2026-11-06.

The user chooses forecast supply that includes confirmed, requested, and unspecified hours. Compared with confirmed-only supply, forecast totals reveal proposed load as well as agreed load. Status totals must therefore remain visible.

Each confirmation replaces one request with identical person, path, percentage, and resolved dates. Partial matches stay separate. This prevents copied approval lines from counting twice while preserving unmatched requests and duplicate commitments.

Pins retain their own status. A pool contributes its remaining hours after child reservations consume it. Same-path pool lines share that remainder in proportion to their hours. Calculated views show active bookings while source files retain the original facts.
